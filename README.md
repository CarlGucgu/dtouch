# dtouch

A simple dostouch written in C

# Installation

Please download the releases and run

If pull by source code, compile in TurboC2.0/tcc not vc

# System Requirements

Tested on 8086 FreeDOS, Other DOSes are not yet clear.

# How to use

TOUCH [-t YYYYMMDDHHMMSS] <filename>


TOUCH <filename>

You can also get help by 

`` TOUCH -h ``
